# Roadmap

1. Stable server core, configuration and structured logging.
2. Authentication, authorization, account recovery and audit trail.
3. Independent-drive storage abstraction and safe file operations.
4. Upload/download, resumable transfers, checksums and conflict handling.
5. Desktop client integration.
6. Recycle bin, versions and backup/restore.
7. Windows Service installer and secure LAN access.
8. Storage Spaces and SMB integration.
9. Media library and streaming.
10. Android camera backup and remote access.
11. Web dashboard.
12. iOS client and Linux server port.

Each milestone requires automated tests and documented recovery procedures.
