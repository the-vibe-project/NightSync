# NightSync v0.5 — Windows live client

## Implemented in the Windows desktop client
- Connect to local server at `http://127.0.0.1:8787`.
- Remote server profiles require HTTPS; HTTP is accepted only for loopback testing.
- Calls `/health` and `/api/v1/status`.
- Displays real server version, uptime, process memory, Go runtime, goroutine count, storage used/free and storage path.
- Lists files from `/api/v1/files`.
- Uploads a selected local file (server enforces 50 MB maximum).
- Downloads selected file.
- Deletes selected file after confirmation.

## Not implemented
- Android live API integration. Android cannot use 127.0.0.1 to reach a different PC, and the server is intentionally loopback-only. Secure LAN/TLS and authentication must be implemented before mobile access.
- Real account login, Member/Admin authorization, encryption at rest, recycle bin, folder sync, camera backup.
- The Admin/Member selector remains a UI preview, not security.
- CPU percentage, connected-device count and hardware drive health are not provided by the current server API.

## Test
Start NightSync Server on the same Windows PC, open NightSync Desktop, choose Connect server and use `http://127.0.0.1:8787`. Test the health endpoint, then open Files to list/upload/download/delete non-sensitive test files.
